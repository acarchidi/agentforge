Privacy Policy

AgentForge API and MCP server. Last updated November 4, 2026.

What AgentForge is

AgentForge is an API and remote MCP server that returns safety checks and data about public blockchains: transaction simulations, signature decodes, address screening, token risk scores. There are no user accounts, and no API keys.

What we receive

Each request contains the inputs you send, such as wallet and contract addresses, transaction data, typed data or text. We use them only to produce the response. We do not store request or response bodies.

What we log

  • Usage events: the endpoint or tool name, the chain, success or failure, the error type, latency, the input and output sizes, and a timestamp.
  • Payments: for paid calls, the amount, the payment network and scheme, and the on-chain transaction hash. These are already public on the blockchain.
  • Client identifier: a salted one-way hash of the paying wallet address. For MCP calls, it is a hash of the MCP session ID, or of the IP address and user agent when there is no session. We use it to apply the free daily MCP cap and to count repeat usage. We do not store raw IP addresses in our analytics.
  • Feedback: if you send feedback through /feedback, we store your message and any contact detail you include.

We delete usage events after 90 days.

Third parties

To answer requests, we query public blockchain RPC nodes and data providers (for example Etherscan, CoinGecko, GeckoTerminal, DexScreener and DefiLlama) with the addresses or tokens you ask about. Some text endpoints, such as summarize, translate and sentiment, send your text to Anthropic's Claude API. Payments are verified and settled through the Coinbase Developer Platform x402 facilitator. The service runs on Vercel, which keeps standard request logs under its own policy.

What we don't do

We do not sell data, run advertising, or use cookies or trackers on the API. We never ask for private keys or seed phrases, and our tools never sign transactions or move funds.
